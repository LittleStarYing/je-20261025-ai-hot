Shopify 最近
宣布放弃 React Native
，将用 Swift 和 Kotlin 重写其旗舰应用。

随着 AI 模型质量的显著提升，移动端负责人 Mustafa Ali 重新评估了 Shopify 对 React Native 的投入，认为现在在移动端跨平台维护原生代码库的收益与成本比已经高于使用抽象层。

这一想法转变发生在 Shopify 于 2020 年
宣布 React Native 是其移动端架构的未来
之后，又
在 2025 年再次确认了这一承诺
，当时所有应用已成功完成为期 5 年的 React Native 迁移。

当时选择 React Native 的理由有三点：避免重复开发相同功能、人才可跨平台复用，以及把更多时间花在为用户提供价值上，而不是费力追赶功能对齐。

Shopify 当时称，采用该框架后开发效率得到提升，应用不仅加载极快（屏幕加载时间低于 500 毫秒）且非常稳定（无崩溃会话超过 99.9%）。

React Native 的热重载和 TypeScript 等功能也被认为是显著提升开发效率的利器。
