我们似乎正在进入人工智能代理的复兴时期。

 Meta 面向消费者的新型人工智能代理 Muse 在发布后不久就登上了 App Store 排行榜榜首，据 Apptopia 估计，在美国拥有 60 万日活跃用户。

人工智能代理平台 Instinct 的同名创始人正在以 25 亿美元的估值筹集资金，该平台一直在科技行业风靡。

不过，在幕后，它与最初的平台 OpenClaw 有一些明显的相似之处。

在过去一周左右的时间里，一些社交媒体用户声称 Muse 是直接构建在 OpenClaw 之上的。

这两个平台对核心文件使用相同的名称（SOUL.md、内存、工具等），并且在文档中有很多相似的内容来控制个性、语气等（“真正提供帮助，而不是表现性帮助”）。

他们也有类似的设计。

一位 Reddit 用户辩称，“Muse 只是一个构建在 OpenClaw 之上的包装应用程序”——声称它可能还带来了该平台的重大安全风险。

 “只有非科技人士才会相信炒作。

”
Meta 否认了这一说法。

 Meta 超级智能实验室产品负责人 Nat Friedman 在 X 上写道，Meta “从头开始”构建了 Muse。

不过，他承认 Muse “作为一款产品深受 OpenClaw 的启发”。

他说，在一月份第一次使用 OpenClaw 后，他为 Meta 的团队购买了数百台 Mac Mini。

他的目标是通过 Muse 建立一个类似的平台，“我们可以让这个平台安全可靠、易于使用，并扩展到数十亿人。

”至于为什么 OpenClaw 文件名和行被保留，弗里德曼表示，团队相信斯坦伯格已经把这些事情“完全正确”了。

本能似乎不太直接衍生。

但与 OpenClaw 当时具有革命性的消息传递功能一样，它允许用户通过消息传递工具直接与人工智能代理进行通信，人们一直将其用于相同类型的日常个人助理式用例，这使得 OpenClaw 获得了关注。

一位 Instinct 用户在 X 上称赞人工智能代理填写了网络内医生就诊的文件、取消订阅、组织单身派对、预订假期活动、预订 DMV 预约、支付未付的路费等等。

另一个人说，他们的本能特工负责找回他们留在加拿大一家酒店的丢失物品​​。

即使这两个平台都是从头开始构建的，但很明显它们对 OpenClaw 的贡献有多大。

OpenClaw 并没有发明人工智能代理的概念，但在短短 10 个月内，它就将它们从概念验证变成了真正有用的东西。

它被拼凑成一个单人周末项目，并在用户的个人电脑上运行，以用户与其他人交谈的方式进行交谈：在 WhatsApp、Telegram、Slack、Teams 或 Discord 等消息平台上。

大约一周内，它在 GitHub 上吸引了 200 万访问者和 100,000 颗星，促使人们购买 Mac Mini 来 24/7 运行他们的代理，激励人们创建一个供 AI 代理“聊天”的社交媒体网络，并在世界各地为 OpenClaw 用户引发一系列面对面的聚会。
