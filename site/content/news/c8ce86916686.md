Meta 制定了一项新计划，旨在鼓励人们为其 Horizo​​n 社交平台制作游戏。

该公司今天发布了两款新的开发工具，可让您使用人工智能提示创建游戏：Horizo​​n Create（一款移动应用程序）和 Horizo​​n Studio（一款提供更精细控制的浏览器应用程序）。

这些应用程序将提供抢先体验，感兴趣的用户可以注册等待名单。

Meta 将让你可以在手机上使用 AI 构建游戏
Meta 的 Horizon 平台的下一步发展涉及人工智能生成的视频游戏。

Horizo​​n 作为一个平台一直在苦苦挣扎，但 Meta 计划让这些新的 Horizo​​n 游戏获得更大的影响力：它将让使用 Horizo​​n Create 和 Horizo​​n Studio 制作的已发布游戏在 Facebook 和 Instagram 上得到推荐，并且这些游戏也可以玩。

“浏览 Instagram 的人可以点击你的游戏剪辑，并在几秒钟内进入多人游戏会话，无需下载应用程序或被重定向，”Meta 说。

 “你的游戏本身就存在于人们已经发现内容并与朋友联系的提要中。

”该公司表示，“吸引人、稳定、具有文化相关性并吸引玩家回归”的游戏将获得更大的影响力。

该公司宣布这一消息之际，Roblox（一个与 Horizo​​n 类似的平台，但更受欢迎）也在大力推动人工智能驱动的开发，其中包括其移动应用程序中的一项功能，同样允许用户通过提示生成游戏。

Meta 发布了关于 Horizo​​n 的消息，Horizo​​n 是一款 VR 应用程序，最近主要关注移动设备。

随着 Meta 将人工智能融入到几乎所有它能做的事情中，人工智能也成为 Horizo​​n 的重要组成部分也就不足为奇了。

为人们提供快速制作这些内容的工具可以为人们提供更多玩游戏的选择。

我非常怀疑一堆人工智能生成的游戏是否会像手工制作的体验一样吸引人，但在 Create 和 Studio 中制作的游戏听起来好像它们至少具有视频游戏的元素（不像谷歌的 Project Genie，它可以创建简短但空洞的人工智能生成的互动体验）。

 Meta 在博客文章中表示：“两者都使创作者能够将任何想法转化为完整的 2D 或 3D 手机游戏，并配有进度系统、平衡难度、艺术指导、多人游戏等，然后根据他们的标准完善每个元素。

”
Meta 可能还有很长的路要走，才能达到 Roblox 的规模，后者拥有 1.23 亿日活跃用户。

相比之下，Horizo​​n 还没有真正起飞。
